# 0.0.6

## [Added]
- `MysteryBox.CreateBox()` API method: programmatically create a Mystery Box and its world item from a macro without opening any UI.

# 0.0.5

## [Added]
- Portable Mystery Box items: full box configuration is now embedded into item flags on every save/edit/regenerate.
- Auto-install hooks: when a GM imports a Mystery Box item from a compendium (into World Items or onto an actor sheet), its configuration is automatically registered in world settings.
- Improved validation when opening a box: players see a clear error if the box config is missing, directing them to ask the GM to import the item.

# 0.0.3

## [Added]
- Raffle mode for Mystery Boxes: weighted random selection as an alternative to independent percentage rolls.
