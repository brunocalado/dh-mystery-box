# Changelog

## [Added]
- Mystery Box Manager now groups boxes by rarity tier (Common, Uncommon, Rare, Legendary) with color-coded section headers.
- Manager window widened to 900px with a fixed 4-column grid layout.
- Visual shimmer + shake effect on Mystery Box item icons in the actor character sheet.
- Raffle mode probability display: each item row shows its draw probability as `(XX.XX%)` next to the weight, updating live on slider drag.
- "Sound Only" opening style: plays sound with no animation.
- "None" opening style: fully silent, no sound and no animation.

## [Changed]
- Default fallback for opening style restored to "Video".
